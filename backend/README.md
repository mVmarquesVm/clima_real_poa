# Backend — API do Forno Alegre

> Ficha da CitizenTech: ver o [README principal](../README.md).

**Disciplina:** Web Development

## O que vai nesta pasta
- API em **FastAPI + Uvicorn**, com banco **SQLite**.
- Lê as estações no ThingSpeak e consome as APIs externas (satélite, Defesa Civil, Open-Meteo); as chaves ficam só no servidor.
- Cruza os dados e aplica as regras de recomendação por atividade.
- CRUD de locais de lazer e de pontos de hidratação.

## A preencher
- Como rodar, variáveis de ambiente (`.env.example`) e lista de rotas.
